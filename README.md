# Sistema Web de Citas Médicas Portable

Prototipo académico desarrollado para la asignatura Interacción Humano-Computador (UNEMI).

## Tecnologías
PHP, HTML, CSS y SQLite (base de datos embebida).

## Instalación
1. Descargue o clone el repositorio.
2. La carpeta `php/` no se incluye por su tamaño. Descargue PHP desde php.net, colóquelo en una carpeta llamada `php/` dentro del proyecto y active la extensión pdo_sqlite en php.ini.
3. Ejecute `EJECUTAR_SISTEMA.bat`.
4. Abra http://localhost:8000 en el navegador.

## Acceso

La base de datos `citas_medicas.db` se crea automáticamente en la primera ejecución.
